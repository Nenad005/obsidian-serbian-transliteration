# Security

Please do not post sensitive vault contents or exploit details in a public issue.
Use [GitHub private vulnerability reporting](https://github.com/Nenad005/obsidian-serbian-transliteration/security/advisories/new)
if it is enabled. Otherwise, contact the maintainer using the contact options on
[their GitHub profile](https://github.com/Nenad005), or open an issue requesting a
private contact channel without including sensitive details.

Include the plugin and Obsidian versions, operating system, a minimal synthetic
reproduction and the expected impact. Do not attach your personal vault.

Only the latest published version is supported for security fixes. The plugin
uses no remote services, telemetry or credentials.
